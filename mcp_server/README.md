# Intangible Valuation MCP Server

Model Context Protocol server exposing the [Intangible Valuation](../README.md)
library as **14 tools** covering 124+ valuation formulas.

The tool surface is defined once in `tool_surface.py` and shared by the stdio
server (`server.py`, generated by `../scripts/generate_mcp.py`) and the hosted
HTTP endpoint (`../api/mcp.py`).

## Run (stdio)

```bash
pip install -e "..[mcp]"
python server.py
```

## Tools

`valuation_time_value`, `valuation_discount_rate`, `valuation_cost_approach`,
`valuation_market_approach`, `valuation_income_methods`, `valuation_ip`,
`valuation_technology`, `valuation_customer`, `valuation_human_capital`,
`valuation_goodwill_ppa`, `valuation_impairment`, `valuation_royalty_analysis`,
`valuation_simulation`, `valuation_compliance`.

Each tool takes a `method` argument selecting the formula, plus that formula's
parameters. See the repo `README.md` and `docs/mcp.md` for details.
